Research Overview

Investigating trustworthy machine learning, weak-label validity, and telemetry systems.

My work addresses an essential problem in applying machine learning to real-world edge systems: How do we know whether a model's high benchmark score reflects genuine physical knowledge or merely the artifact of rule construction, temporal leakage, and deployment shift?

Stage 01: Edge IoT Telemetry & Traceability Pipeline

Undergraduate Thesis · 2025 – 2026 · Defense Score: 8.9 / 10

Developed an end-to-end telemetry system deployed in a durian orchard using ESP32-S3, SHT30, an ES-SOIL-7-IN-1 Modbus/RS485 sensor, SIM A7682S 4G LTE cellular connectivity, and Firebase Realtime Database.

Rather than treating IoT simply as an LCD sensor readout, each record was structured as traceable telemetry—recording measurements, transmission status, retry metadata, and temporal provenance. A downstream data pipeline transformed raw records into structured benchmark views with temporal features.

Stage 03: Observation Contracts & Benchmark Validity

First-Author Working Manuscript · Under Internal Review Prior to Submission

This project treats weak-label benchmarking itself as the primary object of study. When ground-truth agricultural labels are unavailable and targets are derived from temporal rules, standard performance metrics can be misleading.

We formulate observation contracts and effective evidence controls to address:

  • Representation control: Evaluating feature views using matched anchors so score changes represent information gain rather than sample differences.
  • Temporal validity: Separating instantaneous measurements from 3h and 8h history while guarding against temporal leakage.
  • Rule recoverability: Testing whether neural or gradient-boosted models merely memorize the mathematical rules used to create the labels.
  • Deployment transport: Freezing thresholds, preprocessing, and model weights prior to evaluation on an unseen field position.
