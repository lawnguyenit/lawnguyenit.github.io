# cv-lnit

Site CV Astro tĩnh cho https://cv.lnit.id.vn (GitHub Pages). Quy tắc và lệnh: xem [AGENTS.md](AGENTS.md).

```
npm install
npm run sync     # chép dữ liệu từ thư mục content
npm run dev
npm run build && npm run check
npm run pdf      # PDF vào dist/pdf (cần Chromium: npx playwright install chromium)
```
